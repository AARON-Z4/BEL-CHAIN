# User Stories

- As an admin, I want to create a DID so that every user has a verifiable identity.
- As a unit manager, I want to mint an asset passport so that a component has traceable provenance.
- As a supplier, I want to confirm custody handover so that delivery responsibility is provable.
- As an auditor, I want to inspect the event timeline so that I can verify compliance evidence.
- As an operator, I want to request time-bound access so that I can perform assigned work without excessive privileges.
- As a security team member, I want alerts for denied or anomalous access so that I can investigate misuse.
