# User Roles

| Role | Primary permissions |
|---|---|
| Corporate Admin | Configure organizations, policies, roles, high-risk approvals, monitoring |
| Unit Manager | Manage unit assets, scoped identities, allocations, and approvals |
| Project Manager | Manage project-level participants, access and milestones |
| Quality Auditor | Add quality evidence, inspect provenance, generate reports |
| System Operator | View assigned assets; record approved maintenance/custody actions |
| Supplier/Contractor | Submit delivery evidence and see only assigned resources |
| Defence Stakeholder | Authorized read-only provenance and audit visibility |
