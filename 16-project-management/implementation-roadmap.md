# Implementation Roadmap

## Phase 1: Foundation (Weeks 1-2)
Repository, documentation, UI mock data, local Fabric network, roles and basic DID flow.

## Phase 2: Core MVP (Weeks 3-5)
Asset passport minting, RBAC/ABAC checks, custody transfer, audit indexer, dashboard.

## Phase 3: Evidence and Security (Weeks 6-7)
Encrypted document hashing, QR/RFID mock adapter, approval workflow, reports, security tests.

## Phase 4: SIH Demonstration (Week 8)
Demonstrate identity creation → role assignment → asset minting → quality evidence → custody transfer → access request → audit verification.
