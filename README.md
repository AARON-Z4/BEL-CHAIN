# BEL-Chain Documentation

Documentation for BEL-Chain, a permissioned blockchain platform for decentralized identity, access control, digital asset passports, and tamper-evident audit trails for Bharat Electronics Limited (BEL).

## Reading order
1. Project overview
2. Requirements
3. Architecture
4. Identity, access control, assets, blockchain
5. Security, compliance, frontend, implementation, testing and deployment

## Information-handling rule
Never store classified data, raw biometric data, private keys, passwords, or plaintext restricted documents in the ledger, repository, or documentation. Store encrypted content off-chain and immutable hashes/references on-chain.
