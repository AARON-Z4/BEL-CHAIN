# Glossary

- **ABAC:** Attribute-Based Access Control; policy decisions based on attributes such as unit, project, clearance, time, and asset classification.
- **Asset Passport:** Unique lifecycle record for a physical or digital asset.
- **DID:** Decentralized Identifier, a cryptographically controlled identifier.
- **Fabric CA:** Hyperledger Fabric certificate authority.
- **HSM:** Hardware Security Module for protected key operations.
- **NFT-style asset:** A non-fungible, unique ledger record; it is not a public cryptocurrency collectible.
- **Private Data Collection:** Fabric data shared only with authorized organizations.
- **RBAC:** Role-Based Access Control.
- **VC:** Verifiable Credential, a cryptographically signed claim.
